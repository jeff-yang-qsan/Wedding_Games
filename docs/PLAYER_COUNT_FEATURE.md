# 參賽者人數可變設定 - 功能說明

## 概覽
已將遊戲從固定 5 人更新為可變人數設定（1-10人，預設6人），主持人可在建立房間前自由設定參賽者人數。

## 主要變更

### 1. 核心引擎 (game-engine.js)
- **GameRoom 類別**：建構函式新增 `maxPlayers` 參數，預設值為 6
- **驗證機制**：新增 `validateMaxPlayers()` 方法確保人數在 1-10 範圍內
- **GameManager**：`createGameRoom()` 方法支援指定最大參賽者人數
- **JSON 序列化**：正確處理 `maxPlayers` 屬性的儲存和載入

### 2. 用戶界面 (index.html + ui-controller.js)
- **建立房間 UI**：新增參賽者人數設定輸入欄位（1-10人，預設6人）
- **動態顯示**：參賽者列表根據設定人數動態顯示位置卡片
- **狀態更新**：所有人數相關的顯示（`x/y` 格式）都改為動態數值

### 3. 遊戲控制器 (game-controller.js)
- **房間建立**：讀取 UI 輸入的參賽者人數並傳遞給遊戲引擎
- **狀態恢復**：確保重新載入頁面時正確恢復最大人數設定

### 4. 文件更新
- **API 合約**：更新遊戲房間 API 說明最大人數設定
- **規格文件**：更新功能需求說明支援 1-10 人可變設定
- **資料模型**：更新相關約束說明

## 使用方式

### 主持人設定參賽者人數
1. 開啟主持人控制台
2. 在「建立新遊戲」卡片中設定「參賽者人數」（1-10人）
3. 點擊「建立新遊戲」按鈕
4. 系統根據設定顯示對應數量的參賽者位置

### 驗證邏輯
- **有效範圍**：1-10 人
- **預設值**：6 人
- **錯誤處理**：超出範圍或無效輸入時自動使用預設值
- **UI 約束**：輸入欄位設定 min="1" max="10" 防止無效輸入

## 測試檔案
- `test-player-count.html`：功能驗證測試頁面，可測試各種人數設定和驗證邏輯

## 向後相容性
- 現有儲存的遊戲資料會自動使用預設 6 人設定
- 舊的 GameRoom 建構函式呼叫仍然有效（使用預設值）
- UI 顯示會自動適應不同的最大人數設定

## 技術細節

### 資料流程
1. 主持人在 UI 輸入人數 → 
2. game-controller 讀取並驗證 → 
3. GameManager.createGameRoom(null, maxPlayers) → 
4. GameRoom 建立並設定 maxPlayers → 
5. UI 根據 gameRoom.maxPlayers 動態顯示

### 儲存和載入
- LocalStorage 中的 `currentGameRoom` 包含 `maxPlayers` 屬性
- 頁面重新載入時會正確恢復參賽者人數設定
- 參賽者列表顯示會根據已儲存的 maxPlayers 調整

## 已知限制
- 遊戲進行中不能修改參賽者人數（需重新建立房間）
- 最大 10 人限制（可在需要時調整 GameRoom.validateMaxPlayers 方法）
- UI 佈局在 10 人時可能需要優化顯示效果
