# 主題配置系統

## 主題概述
數字抽籤遊戲現在支援兩套主題配色，可通過 `config.json` 進行切換。

## 可用主題

### 1. 米黃奶油色主題 (wheat-cream) - 預設
- **背景漸變**：淺土黃色 (#f5deb3) → 純白色 (#fefefe) → 象牙色 (#fffff8) → 皮膚色 (#f4c2c2)
- **主要按鈕**：金黃色 (#daa520) → 秘魯色 (#cd853f)
- **文字顏色**：深金棕色 (#8b5a3c)
- **適用場景**：溫馨婚禮、優雅聚會

### 2. 浪漫粉色主題 (romantic-pink)
- **背景漸變**：粉色 (#ff9a9e) → 淡粉色 (#fecfef) → 淡粉色 (#fecfef) → 粉色 (#ff9a9e)
- **主要按鈕**：亮粉色 (#ff6b9d) → 柔粉色 (#ff8fab)
- **文字顏色**：藍灰色 (#5a82a3)
- **適用場景**：浪漫婚禮、粉色主題活動

## 主題切換

### 在 config.json 中切換
```json
{
  "ui": {
    "theme": "wheat-cream"    // 或 "romantic-pink"
  }
}
```

### 技術實現
- 使用 CSS 變數 (:root) 定義配色
- 通過 JavaScript 動態添加主題類別到 body
- 自動載入和應用主題配置
